# apps/web

Next.js frontend. Right now it is the clickable prototype from `docs/frontend.md`: 8 screens on mock data, glassmorphism UI.

## Run

```
cd apps/web
pnpm install
pnpm dev            # http://localhost:3000
pnpm lint && pnpm typecheck && pnpm build
```

Mocks are on unless `NEXT_PUBLIC_USE_MOCKS=false`. See `.env.example`.

## How it is put together

| Path | What |
|---|---|
| `src/app/(auth)/login`, `src/app/(app)/*` | Routes. Pages are thin Server Components |
| `src/components/<feature>/` | Feature components (dashboard, dna, studio, editor, variants, comments, reports) |
| `src/components/ui/` | Shared primitives: glass card, button, badge, form fields, loading/empty/error states, job progress |
| `src/lib/api/` | `types.ts` (planned API shapes), `client.ts` (one typed fetch client), `hooks.ts` (one TanStack Query hook per resource) |
| `src/lib/mocks/` | MSW handlers and realistic fixtures (Roman Urdu comments, mixed captions) |
| `src/app/globals.css` | Design tokens (`@theme`) and the `glass` / `glass-inset` utilities |

## Reviewing states

The sidebar has a **Mock data** switch: Normal, Slow, Empty, Error. Use it to check that every screen has loading, empty and error states.

In mock mode a page can reload itself once soon after a first visit or a hard refresh. MSW does this on purpose until its worker controls the page, and it goes away with `NEXT_PUBLIC_USE_MOCKS=false`.

## When the backend arrives

1. Replace `src/lib/api/types.ts` with types generated by `openapi-typescript` from the FastAPI schema.
2. Delete the MSW handler for each endpoint as it ships.
3. Swap the mocked login, Instagram connect and upload for Supabase Auth, the OAuth redirect and a presigned R2 upload.

## Tests

```
pnpm test        # Vitest and Testing Library, next to the code as *.test.tsx
pnpm test:e2e    # Playwright flows in tests/, against the MSW mocks
```

First run of Playwright needs `pnpm --filter @fyp/web exec playwright install chromium`. To use an installed Chrome instead, set `PLAYWRIGHT_CHANNEL=chrome`.
